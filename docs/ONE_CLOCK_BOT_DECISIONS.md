# Paper decision publication

The existing private ledger backup wakes the One Clock projection after each backup pass. Its worker follows only verified byte ranges, independently of trading and private backup progress. A separate durable checkpoint retries the same range through its immutable publication intents after interruption. One producer owns each public bot-audit stream. Preserve its checkpoint and the private archive on runner replacement.

The public document contains the tracked paper username, one of the nine audit outcomes, allowlisted action, and age of the snapshot at decision time. Only the original QQQ OI Skew account can supply the anchored meter. Its run digest and qualified snapshot/anchor preserve resets. Raw aliases, account states, symbols, sizes, broker responses, credentials, reasons and private evidence bytes stay private. Legacy records without provable identity, strategy assignment or paper origin remain unqualified for recorded publication. R2 commit upload and observer receipt determine availability.

Use `python -m crassus.crassus.one_clock_decisions LEDGER --origin reconstructed --available-at ISO_OFFSET_TIME` from the repository root to replay old archives at a declared availability time. Choose `synthetic` for simulated inputs. This path only prints sanitized observations. The source check runs the actual Python publication path against an in-memory private archive and public store, ingests the emitted bytes with the Worker and exercises the browser adapter before and after its receipt.

Publish the API and browser through their normal release lanes. In the existing paper runner configure a separate public R2 credential with `CRASSUS_ONE_CLOCK_PUBLIC_ACCOUNT_ID`, `CRASSUS_ONE_CLOCK_PUBLIC_ACCESS_KEY_ID`, `CRASSUS_ONE_CLOCK_PUBLIC_SECRET_ACCESS_KEY`, and `CRASSUS_ONE_CLOCK_PUBLIC_BUCKET` pointing to the existing public publication bucket. Its logical writer scope is `publications/v1/bot-audit/`; the private archive remains under its current credentials. Keep a single publisher and check head, scope and a naturally retained decision after promotion. The ordinary observer picks up the three streams in its existing bounded invocation. Deactivating this publisher stops new decision publications and leaves retained receipts available.

The Crassus Docker build context contains only `crassus/`. Its local `one_clock_publications.py` is the byte-identical packaged copy of `market_data/live_market/publications.py`; the parity test checks both copies so a wire-contract change cannot pass independently.
